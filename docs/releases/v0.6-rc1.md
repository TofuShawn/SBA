# SBA v0.6-rc1

First release candidate of the 0.6 cycle: the theme layer separates into a
live-switchable first-class component, the capability matrix reaches the
engine menus, the report ships with the release as standalone assets under
its own license, and its implementation walkthroughs are rewritten to the
current code. **rc — the IKB theme (International Klein Blue: white /
black / 水洗藍 X / 黃 O) lands in 0.6.0.** Details per decision:
`docs/decisions.md` (D64–D65).

## Theme layer (live-switchable)

- The theme becomes a first-class layer: `PALETTE` gains the chrome and
  button token sets (board plate/frame, command bar, badge, chart axes,
  hist dot, the full ChamferButton paint set incl. disabled + hatch), and
  every one of the 18 previously hard-coded paint sites reads the palette
  at paint time.
- `set_theme()` performs the live switch — module-global rebind + QSS
  reapply + widget-wide repaint — persisting to `[session] theme`; the
  theme QSS moves to `static/<theme>.qss`. The Endfield (dark) theme is
  pixel-identical to v0.5.0.
- The config rewriter covers escaped basic strings now (the theme key
  rides `[session]`).

## Capability matrix in the UIs (D65)

- Engine menus follow the board size: the MCTS family has no Normal
  backend (the C kernels serialize Ultimate layouts only). The TUI setup
  selects, the QtUI `ai_x`/`ai_o` combos (the game-type combo was never
  connected to a change handler — fixed) and the bench TUI board select
  all rebuild per board size with capability-aware fallbacks.
- `bench` validates explicit Normal pairs and ships capability-valid
  defaults (Minimax Pro / Minimax / Solver) instead of the MCTS-family
  benchmark set.

## Config surface sweep

- Orphan keys dropped from the defaults (`progressive_widening`,
  `early_stop`, `reuse_cache` — their only consumers were the python
  engines v0.5.0 retired); the deleted keys (`bitboard`, `object_pool`)
  are unlisted from the Settings page; python-fallback labels rewritten
  to the C-only reality; the tracked `config.toml` drops the dead keys
  and the D-era comment clauses.

## Report: shipped assets, license, deep rewrite

- The report ships as standalone single-file release assets beside the
  zip: `SBA-<tag>-report.html` (zero-dependency static build, CJK fonts
  subsetted and embedded) and `SBA-<tag>-report.pdf` (Chrome-printed A4,
  pypdf footer overlay, 38 pages). The Noto Sans TC VF is vendored
  in-repo (OFL) — no system fonts needed on the build machine.
- **License split**: code GPL-3.0-or-later; the authored works (the
  report set, stylesheets included, and the tutorials) are **CC BY-NC
  4.0** (`LICENSE.docs`); the engineering records stay GPL. Embedded
  components carry their own licenses (Noto = SIL OFL 1.1; highlight.js
  theme = BSD-3-Clause, embedded with attribution; MathJax 3 =
  Apache-2.0 build-time SVG).
- The report's five implementation sections are rewritten to the current
  code: the Rust state layer (§2.4), the C evaluator (§3.3), the
  C-backed MCTS family (§3.5), `sba_minimax_pro` (§5.3), C tree root
  parallelization with the D63 ownership rule (§5.4). The retired
  python walkthroughs live on in git history and `archive/python-reference`.

## Dependency / tooling

- mypy 2.4.x (the FFI gate validated under the major bump), pytest-cov
  floor 7.1.0. The release workflow builds the report set itself (npm ci,
  vendored font, preinstalled Chrome).
- Suite 191 python tests; coverage floor 65 holds (65.08%); lint /
  format / mypy / pip-audit gates unchanged.
- Merges are squash-only now (repo setting): one commit per PR on main —
  the release tag maps to exactly the shipped content.

## Packaging

- Requires Python 3.12; torch stays optional (training only; the
  AlphaZero engine type requires torch + a trained model). Both native
  DLLs ship in the Windows package; the report assets ship as separate
  single-file downloads.
- License: code GPL-3.0-or-later; the report/tutorials CC BY-NC 4.0 (see
  the License section in the release notes and the README).
