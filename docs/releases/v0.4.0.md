# SBA v0.4.0

This release completes the Rust-first core consolidation: self-play moves
into a pure-Rust executable, the tree search reaches byte-equal parity with
the Python reference, and the repository restructures around function rather
than language. It also answers an external audit in full. Details per
decision: `docs/decisions.md` (D53–D61).

## Correctness (external audit response, D54)

- `save_engine_config` rewrites TOML safely: section-bounded replacement,
  every legal scalar spelling accepted, verify-before-write via a sibling
  temp + `os.replace` — a hand-edited `300_000` can no longer corrupt
  `config.toml`.
- Engine guards: zero/negative budgets clamp at dispatch, an empty search
  root returns None with a last-resort legal move, the legacy rollout-only
  DLL loads again, and the Rust state layer validates every handle
  (use-after-free returns `ERR_CLOSED`, double free is a no-op).
- The external audit's 29 findings (1 blocker / 13 major / 11 minor / 4 nit)
  are answered: 26 fixed, 2 partially with the remainder recorded, 1 handled
  by annotation.

## Rust core (Phase A, D55–D59)

- **`sba-core` crate** (burn 0.16; wgpu default, cpu for CI — no CUDA):
  hand-written AZNet loads PyTorch safetensors 1:1, inference parity vs
  torch pinned at ≤1e-5 (with a documented upstream `cubecl` tensor-core
  workaround), encode parity bitwise.
- **`sba_selfplay` exe**: AlphaZero self-play with leaf-parallel wave search
  ported 1:1 from the Python trainer (virtual-loss rounds, batch 256) —
  search parity **100% top-1 / KL 0.0000** on 200 positions, visit vectors
  byte-equal. One safetensors record per game; JSONL events on stdout; a
  deadline watchdog kills wedged processes; K-process rounds split games and
  seeds collision-free.
- **Training wiring**: `--selfplay-engine auto|rust|python` (auto probes the
  exe, python mp.Pool stays as the fallback path), per-game in-order absorb
  with retry-once, `TrainCfg`/`TrainCtx`/`RoundArgs` dataclasses, honest
  engine labels on the training TUI.
- **Throughput**: 0.26x of the Python path — measured backend-bound (the
  burn/cubecl kernel runs ≈13x behind torch/ROCm-HIP on RDNA3; multi-queue
  and multi-process attempts are recorded, not hidden). The Python self-play
  path remains available and is the faster route today.
- The Python wave-search reference is frozen as golden vectors
  (`tests/golden/`), so the parity anchor survives any future retirement of
  the Python implementation.

## Recipe (D58)

- Pure-network leaf values (`ROLLOUT_WEIGHT = 0`) — the standard AlphaZero
  recipe, aligning training with the exe. Layer-4 strength re-read 66.2%
  with the pick-policy asymmetry recorded as measured.

## Structure (D60/D61)

- `native/` dissolves into `src/`, organized by function: the two Rust
  crates live under `src/` behind a root workspace (shared `target/`), the
  C engines sit flat beside the modules they serve, and the dev harnesses
  move to `src/tools/`.
- The Python modules group into function packages — `core/`, `engines/`,
  `az/`, `analysis/`, `ui/`, `session/` — one-level packages; `config.py`
  stays the root leaf; the DLLs land beside their bindings.

## Tooling / CI

- `python dev.py` — every development gate in one runner (build, test-rust,
  clippy, clippy-core, cgate, bench-selfplay, self-test).
- CI runs on `main` and `dev`, ubuntu + windows: ruff, C `-Werror`, clippy
  `-D warnings` on both crates, a blocking `pip-audit` gate with a documented
  residual baseline, and the full suite — 201 tests.
- The K-process watchdog is race-free on slow CI (post-join kill-all sweep).

## Packaging

- Requires Python 3.12; `safetensors` added to the runtime deps; direct
  dependencies carry upper bounds and audit clean.
- The Windows package ships both native DLLs (`sba_engine.dll`,
  `sba_game.dll`) — no compiler needed on the user machine.
- Third-party dependencies are installed separately and keep their own
  licenses: PySide6 (LGPL-3.0), Textual and rich (MIT), numpy (BSD-3),
  torch (BSD-style). This project is GPL-3.0-or-later.
