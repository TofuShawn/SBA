# SBA v0.3.0

This release moves the entire AI layer onto native code paths and turns the
CLI tools into live dashboards. Details per decision: `docs/decisions.md`
(D40–D52).

## Native engines

- **Rust state layer** (`native/sba-game`, D48/D50): the game-logistics
  bitboard state as a cdylib behind a ctypes bridge. Parity with the Python
  reference is pinned by a 150-game seeded fuzz (legal-move order included);
  the Python implementation stays as reference and fallback
  (`engine.rust_game = false` in `config.toml`).
- **Bulk exports** (D50): serialize / planes / clone_apply — the AlphaZero
  encode and PUCT-expansion paths drop from per-cell Python materialization
  to one FFI round trip per state.
- **C RAVE / GRAVE trees and C Minimax Pro** (D51): all nine menu engines
  now have native paths. AMAF tables with ref-node stamp dedup; the solver
  gains exact 3-word transposition keys, killer moves, LMR and
  aspiration-window iterative deepening.
- **Batched handle frees** (D52): deferred FFI frees (512-batch) flipped the
  stage-2 self-play mix from a 26% regression to **1.37x faster** than the
  Python game.
- **Engine layer split** (D47): `ai.py` became eight modules behind a stable
  facade; `from ai import ...` keeps working.
- `native/bench_rust.py` — the measurement harness behind the numbers above.

## Training

- Numbered checkpoints (D46): every `--ckpt-every` point survives (the long
  campaign blocker).
- Self-play inference −33% per position: encode once per leaf, GPU-tiled
  batching, one sync per round.
- Per-game training-curve CSV (`--csv`), resume-safe.
- workers=8 hardening: staggered HIP-context init, worker crash capture
  (`logs/tui-crash.log`, `logs/mp-worker-*.log`).

## Interfaces

- `python sba.py` — one entry point for TUI / bench / build-tables /
  self-test / train-az / eval-az (D43).
- rich CLI output: tables, progress bars, eval gauges (D42).
- Textual dashboards `--bench-tui` / `--train-tui` (D44/D45): two-page
  layout — parameters page plus live monitor.
- Assistant policy heat (D40): AZNet priors tint empty cells, display-only.

## Tooling / CI

- ruff gate (F/E9/E7, zero findings) and advisory clippy on the Rust crate;
  Dependabot keeps pip and GitHub Actions weekly-fresh.
- Line endings normalized repo-wide via `.gitattributes`.

## Packaging

- Requires Python 3.12; dependencies raised (PySide6 ≥ 6.12, Textual ≥ 8.2.8,
  rich ≥ 15).
- The Windows package ships both native DLLs (`sba_engine.dll`,
  `sba_game.dll`) — no compiler needed on the user machine.
